# shadowproxy-site

Marketing site for **ShadowProxy** — a negotiation strategy assistant powered by multi-agent simulation.

Live: [shadowproxy.space](https://shadowproxy.space)

## Pages

- `index.html` — Home / Product / Demo / Contact
- `about.html` — company, founder, stage
- `technology.html` — negotiation engine + AWS stack
- `roadmap.html` — product roadmap
- `trust.html` — trust & security
- `privacy.html` / `terms.html` — legal
- `CNAME` — GitHub Pages custom domain

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```
