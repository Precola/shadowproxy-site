# shadowproxy-site

Marketing site for **ShadowProxy** — a negotiation strategy assistant powered by multi-agent simulation.

Live: [shadowproxy.space](https://shadowproxy.space)

## Pages

- `index.html` — landing page (Negotiation / Strategy AI)
- `technology.html` — how we use AWS (train / sim / infer / data)
- `privacy.html` — privacy policy
- `terms.html` — terms of use
- `CNAME` — GitHub Pages custom domain

## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```
